# Experiment 2: Prompt Engineering Comparison Using Gemini AI

## Aim
To demonstrate how enhanced prompts improve the output quality of a language model compared with baseline prompts.

## Problem Statement
To send a baseline prompt and an enhanced prompt to Gemini AI, display both responses, and compare their word counts and readability.

## Technologies Used
- Python
- Google Colab
- Google Gemini API
- Google Gen AI SDK

## Procedure
1. Install the required Google Gen AI library.
2. Create a Gemini API key using Google AI Studio.
3. Store the API key securely as an environment variable.
4. Define a baseline prompt.
5. Define an enhanced prompt with a role, analogy, and output-format instructions.
6. Send both prompts to Gemini AI.
7. Display and compare the responses.

## Baseline Prompt
Explain recursion.

## Enhanced Prompt
You are a computer science professor. Explain recursion to a beginner using a simple real-world analogy. Write exactly two paragraphs using simple English.

## Expected Output
- Baseline prompt and response
- Enhanced prompt and response
- Word-count comparison
- Brief analysis of the results

## Result
The experiment compares a general prompt with an enhanced prompt. The enhanced prompt gives the model more specific instructions about its role, explanation style, and output format.

## Security
Never upload API keys or other secret credentials to GitHub.
